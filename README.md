# Attendance Management System

A full-stack web application designed to manage and track attendance efficiently. The system allows users to record, view, and manage attendance data through a simple and responsive interface.

## Tech Stack

Frontend
- React.js
- HTML
- CSS
- TypeScript

Backend
- Node.js
- Express.js

Database
- MongoDB

Tools
- Git
- GitHub

## Features

- Add and manage student records
- Mark daily attendance
- View attendance records
- Store attendance data in a database
- Responsive user interface
